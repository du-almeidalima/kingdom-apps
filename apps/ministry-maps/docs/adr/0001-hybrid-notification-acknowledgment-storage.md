# Hybrid Subcollection Storage for Notification Acknowledgments

App-wide notifications need to track user acknowledgments for two access patterns: per-user history pagination on `/profile/notifications` and cross-congregation receipt inspection by the App Admin on `/notifications/:id`. We store per-user history as individual snapshot documents at `users/{userId}/notifications/{notificationId}` (supporting native `orderBy` and `limit(5)` pagination without bloating `users/{userId}` on login), while storing the admin receipt list as a single aggregated map document at `notifications/{notificationId}/acknowledgments/summary` so the parent `notifications/{id}` document stays lightweight and inspecting acknowledgments costs a single Firestore read instead of one read per user.
